How form submission works

The browser checks required fields and input types, then submits the named values to the address in action using the HTTP method in method. GET places form values in the URL and is generally for searches; POST sends values in the request body and is generally used to submit data. This example uses method="post"; a server must be configured to receive and process the submission.
